# Textile

Type anything and watch your words get stitched into fabric, one square at a time.

Textile was inspired by two projects.

[Tobie Tse](https://www.instagram.com/p/DZaR7Jtm5-W/) makes artworks in filet crochet, an old lace technique where a grid of open mesh is filled in square by square to draw pictures and words.

![A filet crochet piece by Tobie Tse reading “just waiting on my luck to change”](/textile/inspiration/tobie-tse.jpg)

[yangyum.zip](https://yangyumzip.vercel.app/app/works/knit/index.html)'s knitting typewriter, a side project that knits whatever you type, is what got me to actually start building this.

![yangyum.zip’s knitting typewriter, with typed words knitted into a sweater-like fabric](/textile/inspiration/yangyum-zip.png)
